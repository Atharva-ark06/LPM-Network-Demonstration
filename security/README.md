# Security learning resources

This folder connects the Longest Prefix Match concept to defensive network-security practice.

## Why it matters

Routing influences the path packets take. That path can affect segmentation, firewall enforcement, intrusion detection, logging, incident investigation, and return traffic. Route selection is only one part of the picture: routing does not replace authentication, access control, encryption, monitoring, or change management.

## Contents

- [Route review checklist](route-review-checklist.md) — questions to ask during an authorized configuration review.
- [Incident-response exercise](incident-response-exercise.md) — a tabletop scenario for investigating unexpected reachability.
- [Routing change-plan template](routing-change-plan-template.md) — a reusable pre-change, validation, and rollback worksheet.

## Boundaries

These materials are educational. The repository does not inspect production routing tables, detect route hijacks, validate firewall policies, or establish that a real network is secure. Use sanitized configuration and authorized lab evidence.
